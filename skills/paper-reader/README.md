## 🎯 这玩意儿能干啥？

你有没有这种体验：

> 收藏了 200 篇论文，一篇都没读完。
> 精读一篇要 3 小时，扫读要 30 分钟，关键信息还容易漏。

**论文速读器**就是干这个的：

```
你把 PDF 扔进来 → 3 分钟后 → 收到一份结构化摘要
```

包含：
- ✅ 研究问题（这论文到底想干啥）
- ✅ 方法（咋干的）
- ✅ 数据集（拿啥干的）
- ✅ 实验结果（干得咋样）
- ✅ 局限性（有啥坑）
- ✅ 一句话总结（适合发朋友圈那种）

## 🔥 核心亮点

### 📌 智能分块
不是简单按字数切——按论文的天然结构（标题、段落、图表标题）做语义分块，保证每个 chunk 自包含。

### 📌 结构化抽取
不是一股脑的摘要，是按字段抽取：

| 字段 | 说明 | 示例 |
|:-----|:-----|:-----|
| `title` | 论文标题 | "Attention Is All You Need" |
| `problem` | 研究问题 | 序列转录模型的计算瓶颈 |
| `method` | 方法 | 自注意力机制 + 多头注意力 |
| `dataset` | 数据集 | WMT 2014 英德翻译 |
| `results` | 关键结果 | BLEU 28.4 → 41.8 |
| `limitations` | 局限性 | 长序列计算复杂度 O(n²) |
| `one_sentence` | 一句话总结 | "注意力机制就够了，不用 RNN" |

### 📌 中英文通吃
英文论文用英文 prompt 抽，中文论文用中文 prompt 抽，不串味。

## 🚀 快速开始

### 安装

```bash
pip install pymupdf openai
```

### 配置

```bash
export OPENAI_API_KEY="sk-你的key"
```

### 运行

```bash
python paper_reader.py paper.pdf
```

输出示例：

```markdown
# 论文摘要：Attention Is All You Need

## 一句话总结
Transformer 用纯注意力机制替代了 RNN，在翻译任务上达到 SOTA。

## 研究问题
序列转录模型的并行化困难与长距离依赖问题。

## 方法论
提出了缩放点积注意力（Scaled Dot-Product Attention）和多头注意力机制。

## 主要发现
Transformer 在 WMT 2014 英德翻译上达到 28.4 BLEU，比之前最好模型高 2+ BLEU。
```
